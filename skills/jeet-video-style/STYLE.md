# Card2Dream 视频品牌风格

取自 c2d-video-factory 的 How-to 模板（`site/template.js`），品牌向视频统一按这个来。

## 配色

| 名称 | 色值 | 用途 |
|---|---|---|
| Navy | `#0B1A4A` | 标题、正文主色 |
| Blue | `#1F6BFF` | 品牌主色、强调词、按钮 |
| Blue 2 | `#3D8BFF` | 渐变、次强调 |
| Mint | `#3CCFB4` | 成功、到账、正向数字 |
| Yellow | `#FFC93C` | 奖励、DP、亮点贴纸 |
| Pink | `#FF7AA2` | 点缀，少量用 |
| 背景 | `#F5F8FF` / `#EEF3FB` | 浅蓝白底 |

## 字体

- **Poppins**（Bold 700 标题，Medium 500 副标题/正文），备选 Inter。仓库 `fonts/` 里有 TTF（SIL OFL）。
- ₦ 符号 Poppins 不一定有字形，缺字时这一个字符用 Inter。

## 版式与节奏（How-to 模板参考值）

- 开场 3.2 秒（标题 + 一句 hook + 蓝鸟 IP 动作）→ 每步 4.2 秒（手机截图 + 点击位置 + 一行说明）→ 结尾 3.8 秒（CTA "Download Card2Dream" + 副标）。
- 动效缓动：出场 ease-out cubic，弹入 back-out，转场 ease-in-out cubic；不要线性匀速。
- 一屏只讲一件事，文字一行不超过约 32 个英文字符。

## 语气

像朋友说话，不说教；可以轻松幽默，但不碰政治、宗教、赌博、地域冲突，不点名运营商。卖点讲"快、稳、靠谱"，不承诺具体收益。

## 素材

Mac 上 `~/Documents/C2D素材库/`：logo、IP 形象（蓝鸟）、App 截图、品牌规范、成片输出。
