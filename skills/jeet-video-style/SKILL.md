# Jeet 视频风格 · 总入口

先读本文件，再按「路由」去读对应子技能的 SKILL.md。子技能都在同一个 skills 目录下（相对路径 `../<技能名>/SKILL.md`）。品牌细节见同目录 [STYLE.md](STYLE.md)。

## 默认规格（用户没说就用这个）

- 画幅 **9:16 竖屏 1080×1920，30 fps**，MP4（H.264 + AAC）。横屏只在用户明确要求时做。
- 时长：热点/梗 8–15 秒；How-to 教程 20–30 秒；福利/规则 10–20 秒。
- 字幕/画面文字：英文为主，可混少量 Pidgin；金额一律用 **₦（奈拉）**，不用 $。
- 安全区：上 220px、下 320px 不放关键文字（TikTok/Reels 的 UI 会挡）。
- 无声预览要明说；不加热门/版权音乐，配乐留给发布时在 App 商用音乐库选。

## 铁律

1. **文字必须 100% 准确**：金额、比例、活动码、App 按钮名都用代码渲染或在图片阶段定稿，不让 AI 视频模型生成。
2. 品牌向视频用 STYLE.md 的配色和字体；内容向（纯流量短剧）可以不带品牌，但不能冒用真人、不编造用户收益。
3. 不用 Nollywood 片段或别人的视频素材；需要类似画面就自己重做。
4. 交付前检查首帧、中段、尾帧、转场：字体、溢出、黑帧、字幕可读；确认分辨率、时长、帧率、有无声轨。
5. 交付时写清：用了哪个风格编号、规格、声音状态、源码位置。
